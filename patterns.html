Pattern 01

Top banner variants.

Sits above the main header, dismissible, dismissal persists in localStorage. Used for time-sensitive announcements - never for marketing.

Four variants, ordered from most-used to escalating-urgency. Only one banner is ever live at a time.

A · Announcement
Use 90% of the time · open applications, new content, soft updates
APPLICATIONS OPEN Saranya Cohort 4 - early & growth-stage agri-tech ventures. Apply by 30 June 2026. Check eligibility →
B · Deadline warning
Use in the final 7 days before a deadline · stronger contrast
CLOSING IN 4 DAYS Saranya Cohort 4 applications close 30 June. Late applications roll into the next cycle (Aug review). Apply now →
C · Informational
Use for context that doesn't drive action · new resource, policy update
FY25 REPORT Our FY25 Impact Report is out - ₹7.2Cr deployed, 70 ventures funded. Read the report →
D · System notice
Use only for operational issues · maintenance, outage, application portal status
SCHEDULED · 22 JUN The application portal will be offline for maintenance 22 June, 02:00-05:00 IST. More info →

Decision rules

  • Choose ADefault. For any open-call or soft announcement. Tea-green background; copper accent for the action verb.
  • Choose BOnly in the final 7 days before a hard deadline. Copper background - full attention.
  • Choose CWhen the goal is awareness, not action. Cream-100 background; low-contrast on purpose.
  • Choose DOnly for operational notices. Soil-brown background - distinct so users learn to read it as system, not marketing.
  • NeverTwo banners at once. Marketing copy. Banners that re-appear after dismissal within 7 days.

Pattern 03

Language toggle - three states.

Trilingual support per the brief - English (primary), Hindi, Assamese. The toggle is permanent in the header; selection persists across sessions. For the v1 design phase, only the English content is built - toggling other languages routes to a "coming soon" page in production.

State 01
English active · default · 100% content coverage
State 02
Hindi active · CMS content + UI strings localised
State 03
Assamese active · localised; KVK + state content primary
